# Archived numerical outputs

These snapshots were generated from the development reproducibility scripts (Python 3.13.5, NumPy 2.3.5). The heterogeneous-cost example (manuscript Table 6; file table5.csv) is analytical; the other CSVs are synthetic. reference_heldout.csv extracts the held-out policy comparison from reference_demo.json. The full JSON reports and vector figures are generated by the documented commands and preserved in CI artifacts. None of the results represents measured LLM performance or actual expenditure.

The numerical snapshots are tracked so readers can inspect the evidence without running code. Do not interpret the synthetic calibration study or reference pipeline as independent empirical validation of the proposed framework.

## Targeted strengthening

strengthening.json archives exact counterexamples, covariance/weighting checks, synthetic routed-subset correlation matrices and paired bootstrap intervals. The generated report is docs/FINAL_RESEARCH_OUTCOMES.md. Run python -m scripts.verify_archive to regenerate in an isolated directory and compare all archived numerical files and the report without overwriting the originals.
